# Требования по странам — как с этим работать

Эта страница для специалиста по визам. Программировать не нужно ничего.
Вся работа — в одном файле с текстом и в трёх командах, которые набираются
в чёрном окне.

---

## Коротко, в чём смысл

Для каждой пары «тип визы + страна» есть запись с требованиями. У записи
два состояния:

| состояние | что значит | видно ли на сайте |
|---|---|---|
| `draft` | черновик, написан начерно | **нет** |
| `verified` | вы проверили и подтвердили | да |

Черновик не просто спрятан — его **физически нет** на сайте. Ни страницы,
ни ссылки, ни строки в поиске. Так сделано нарочно: человек принимает
решение о поездке и деньгах, читая эти требования. Непроверенное лучше
не показывать вовсе, чем показать с оговоркой.

Посмотреть черновики можно только у себя на компьютере, в предпросмотре.
Там каждая такая страница помечена красной полосой.

---

## Где лежит текст

Один файл: **`data/requirements.json`**

Откройте его любым текстовым редактором — «Блокнот», TextEdit, VS Code.
Внутри он выглядит так (это кусочек, настоящая запись длиннее):

```
{
  "visa": "okuw-wizasy",
  "country": "tr",
  "status": "draft",
  "fee": { "tk": "", "ru": "", "en": "" },
  "checkedBy": "не проверено"
}
```

Правила, которые важно не нарушить:

- Текст пишется **между кавычками**: `"ru": "ваш текст сюда"`.
- Кавычки, двоеточия и запятые — не трогать. Они держат файл вместе.
- Внутри текста кавычки `"` ставить нельзя. Если нужны — поставьте «ёлочки».
- `tk` — туркменский, `ru` — русский, `en` — английский. Заполняются все три.

Если случайно сломаете файл — ничего страшного, команды ниже об этом
скажут и назовут строку.

## Что проверить в записи

1. **Список документов.** Написан общий, по нему почти везде одинаково.
   Уберите лишнее, допишите то, что просит именно это консульство.
2. **Куда подаётся** — консульство в Ашхабаде или в другой стране,
   нужна ли запись заранее.
3. **Сроки.** Оставлены пустыми намеренно. Пустое поле честнее
   выдуманного числа: пустое сразу видно, а выдуманное выглядит как
   правда. Впишите то, что действует сейчас.
4. **Консульский сбор — особый случай.** Его можно **не заполнять**,
   и это нормально. Тогда на странице стоит честная строка:

   > Консульский сбор по официальному тарифу — уточняем на консультации.

   Сборы меняются чаще всего и зависят от курса. Устаревшая сумма на
   сайте хуже, чем её отсутствие: человек посчитает бюджет по ней и
   придёт с неверной суммой.

   Если сумму всё-таки вписываете — обязательно поставьте рядом дату,
   когда вы её проверяли:

   ```
   "fee": { "tk": "60 USD", "ru": "60 USD", "en": "60 USD" },
   "feeCheckedOn": "2026-09-12"
   ```

   Без этой даты запись не опубликуется. На странице сумма покажется
   так: «60 USD · сумма проверена в сентябре 2026».
5. **Метки `УТОЧНИТЬ:`** — это вопросы к вам. Найдите каждую, замените
   на ответ. Пока хоть одна осталась, запись публиковать нельзя —
   проверка не пропустит.
6. **Причины отказа** — самое ценное для клиента. Допишите то, с чем
   сталкивались на практике.

## Как посмотреть черновик

Откройте окно с командами в папке сайта и наберите две команды:

```
node scripts/build.js --drafts
node scripts/serve.js
```

Вторая команда напечатает адрес вида `http://localhost:8777` — откройте
его в браузере. Найдите нужный тип визы, там будет список стран.
У страницы-черновика сверху красная полоса:

> **ЧЕРНОВИК — НЕ ПРОВЕРЕНО СПЕЦИАЛИСТОМ**

Правьте текст в `data/requirements.json`, сохраняйте, снова наберите
первую команду и обновите страницу в браузере.

Чтобы закрыть сервер — нажмите `Ctrl+C` в окне с командами.

## Дата проверки — обязательна

У каждой записи есть поле `checkedOn`: когда вы её последний раз
смотрели. Оно попадает на страницу заметной строкой прямо перед
призывом:

> **Информация проверена в сентябре 2026.**
> Требования могут меняться. Точный список подтверждаем на консультации.
> Решение о выдаче визы принимает только консульство.

Дата уходит и в разметку для поисковиков. Без неё запись не
опубликуется.

---

## Раз в месяц: что перепроверить

Сведения о визах стареют молча — страница выглядит так же, а требования
уже другие. Поэтому раз в месяц:

```
node scripts/requirements-status.js
```

Наверху будет раздел **ПОРА ПЕРЕПРОВЕРИТЬ**: там записи, которые не
смотрели больше полугода, и отдельно — суммы сборов старше полугода.

По каждой: откройте требования консульства, сверьте, поправьте что
изменилось и поставьте новую дату в `checkedOn` (а если трогали сумму —
и в `feeCheckedOn`). Если ничего не изменилось — всё равно поставьте
новую дату: она говорит не «мы что-то поменяли», а «мы это видели и
подтверждаем».

---

## Как опубликовать проверенную запись

1. В записи поменяйте:

   ```
   "status": "verified",
   "checkedOn": "2026-09-12",
   "checkedBy": "Имя Фамилия"
   ```

   Дата пишется как год-месяц-день.

2. Соберите сайт **без черновиков** и проверьте:

   ```
   node scripts/build.js
   node scripts/preflight.js
   ```

Если `preflight` написал **МОЖНО ПУБЛИКОВАТЬ** — всё в порядке.

Он не пропустит запись, если в ней остались метки `УТОЧНИТЬ:`, пустые
сроки, не поставлена дата проверки или вписана сумма сбора без даты,
когда её проверяли. Это не придирка: такая страница уже видна людям и
должна быть полной.

## Что уже сделано, а что нет

```
node scripts/requirements-status.js
```

Покажет таблицу: по какой паре «виза + страна» записи нет, где черновик,
где проверено. Ниже — список ваших вопросов `УТОЧНИТЬ:` и пустых полей.

Только вопросы, без таблицы:

```
node scripts/requirements-status.js --todo
```

## Частые случаи

**Записи по нужной стране вообще нет.** Значит, пара ещё не заполнена.
Скажите разработчику — он добавит заготовку.

**Страница не появилась на сайте.** Проверьте, что `status` стоит
`verified` (а не `draft`), и что вы запустили `node scripts/build.js`
**без** `--drafts`.

**После предпросмотра черновик остался в сборке.** Наберите
`node scripts/build.js` без `--drafts` — черновики уберутся с диска.
`preflight` об этом тоже предупредит.

**Страна есть в списке, а страницы по ней нет.** На странице визы
показываются только проверенные страны. Пока их нет, там стоит честная
строка: «Точные требования по направлениям расскажем на консультации».
