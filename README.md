# VisaWay Group — сайт визового центра

Сайт визового центра в Ашхабаде. Три языка: туркменский (основной),
русский и английский. 33 страницы.

Сделан на чистом HTML, CSS и обычном JavaScript. Ни одной сторонней
библиотеки, ни одного обращения к чужим серверам: ни шрифтов, ни счётчиков,
ни чат-виджетов. **Всё, включая шрифт, лежит внутри папки проекта** — сайт
открывается быстро и работает даже при медленном и ограниченном интернете.

## Три правила

1. **Перед любой правкой делайте копию:** `node scripts/backup.js`.
   Одна секунда. Если сломаете — вернёте файлы из папки `backups/`.
2. **После правки `data/site.json`, `data/countries.json` или `partials/`** запускайте
   `node scripts/sync-layout.js`. Без этого изменения не попадут на страницы.
3. **Перед публикацией** запускайте `node scripts/preflight.js`.
   Пока она пишет «Публиковать рано» — публиковать рано.

## Все команды

Все команды запускаются в **Терминале** (на Mac: Программы → Утилиты → Терминал).
Сначала перейдите в папку проекта — это делается один раз за сеанс:

```
cd ~/Desktop/"tasin dunya"
```

### Каждый день

| Команда | Что делает |
|---|---|
| `node scripts/backup.js` | Сохраняет копию сайта в `backups/`. Делайте перед каждой правкой. |
| `node scripts/backup.js --list` | Показывает все сохранённые копии. |
| `node scripts/sync-layout.js` | **Главная команда.** Разносит шапку, подвал, контакты и разметку по всем 33 страницам. Запускайте после правки `data/site.json`, `data/countries.json` или `partials/`. |
| `node scripts/preflight.js` | Проверяет, готов ли сайт к публикации. Ничего не меняет. |
| `node scripts/serve.js` | Открывает сайт локально на `http://localhost:8777`. Остановить — `Ctrl+C`. |

### Изредка

| Команда | Когда нужна |
|---|---|
| `node scripts/sync-layout.js --check` | Проверить, не разошлись ли страницы с шаблонами. Ничего не меняет. |
| `node scripts/measure-speed.js` | Замерить скорость на медленном интернете. Нужен запущенный `serve.js`. |
| `node scripts/optimize-svg.js` | Сжать логотипы. Запускать только если заменили файлы логотипов. |
| `python3 scripts/subset-fonts.py` | Пересобрать шрифты (Inter и Unbounded). Запускать только если добавили текст с новыми символами. |
| `python3 scripts/photos.py` | Подготовить фотографии городов для блока стран: обрезать, ужать, записать источники. |
| `python3 scripts/font-fallback.py` | Пересчитать поправки для запасных шрифтов. Нужно только при смене шрифта. |
| `node scripts/build-seo.js` | Пересобрать карту сайта и разметку отдельно. Обычно не нужна: её запускает `sync-layout.js`. |

> Для команд с `node` нужен установленный Node.js. Если Терминал отвечает
> `command not found: node` — установите его с сайта nodejs.org, обычная
> установка, ничего настраивать не надо.

Телефон, адрес, почта, часы работы и мессенджеры лежат только в

## 1. Шапка, подвал и значки — правятся ОДИН раз

Шапка, подвал и набор значков одинаковые на всех восьми страницах. Держать их
в восьми файлах и править руками — верный способ что-то забыть. Поэтому они
лежат по одному разу в папке `partials/`.

### Что делать

1. Поменяйте нужное в `partials/header.html`, `partials/footer.html`
   или `partials/icons.html`.
2. Откройте **Терминал** и выполните:

   ```
   cd ~/Desktop/"tasin dunya" && node scripts/sync-layout.js
   ```

3. Готово — изменения разошлись по всем страницам сразу.

Короче говоря: **поменял меню или подвал — запусти эту команду,
изменения разойдутся по всем страницам.**

> Для этой команды нужен Node.js. Если Терминал ответит `command not found: node`,
> установите его с сайта nodejs.org (обычная установка, ничего настраивать не надо).

### Хочу только проверить, не забыл ли я запустить

```
node scripts/sync-layout.js --check
```

Эта команда ничего не меняет, а только говорит, какие страницы отстали.

### Как это устроено (можно не читать)

В каждой странице есть парные метки-комментарии:

```html
<!-- header:start nav="wizalar" -->
   ...сюда скрипт кладёт содержимое partials/header.html...
<!-- header:end -->
```

Всё между метками перезаписывается, сами метки остаются. Скрипт заодно делает
две вещи сам: подставляет `../` в путях для страниц внутри папки `wizalar/`
и подсвечивает текущий пункт меню (за это отвечает `nav="..."` в метке).

**Важно:** не пишите ничего между метками прямо в странице — при следующем
запуске это сотрётся. Правьте только файлы в `partials/`.

## 2. ТРИ ЯЗЫКА: как ничего не сломать

Сайт существует в трёх версиях:

| Язык | Где лежит | Для кого |
|---|---|---|
| Туркменский | в корне: `index.html`, `wizalar/…` | основной язык сайта |
| Русский | `ru/` | повседневный язык в Туркменистане |
| Английский | `en/` | переписка с зарубежными вузами и партнёрами |

**Имена файлов во всех трёх папках одинаковые.** Русская версия страницы
`wizalar/is-wizasy.html` лежит в `ru/wizalar/is-wizasy.html`. Так их проще
сопоставлять глазами и так работает переключатель языков.

### Главное правило

**Изменили текст на одном языке — сразу измените его на двух других.**

Переключатель языков ведёт на ту же самую страницу в другом языке. Если
страница есть только на туркменском, ссылка честно уводит на главную нужного
языка — но это временное решение, а не норма.

### Перед публикацией всегда запускайте

```
node scripts/sync-layout.js --check
```

Эта команда ничего не меняет, а проверяет и ругается, если:

- страница есть на одном языке, а на другом её нет;
- в русской или английской версии остался непереведённый кусок
  (сравнивается с туркменским оригиналом — если длинное слово совпадает
  в обеих версиях, это подозрительно);
- ссылка `hreflang` ведёт на несуществующий файл;
- вёрстка страниц разошлась с папкой `partials/`;
- в `data/site.json` остались незаполненные данные.

Если команда завершилась словами «Проверка: всё в порядке» — можно публиковать.

### Что где переводится

| Что | Где править |
|---|---|
| Шапка, меню, подвал, блок призыва | `partials/*.ru.html` и `partials/*.en.html` |
| Адрес, часы работы, языки обслуживания | `data/site.json`, разделы по языкам |
| Телефон, почта, ссылки на мессенджеры | `data/site.json` — они общие для всех языков |
| Тексты страниц | сами файлы в `ru/` и `en/` |
| Значки | `partials/icons.html` — общий, переводить нечего |

После правки партиалов или `site.json` обязательно запустите
`node scripts/sync-layout.js`.

### Название компании не переводится

`VisaWay Group` остаётся как есть на всех трёх языках. В английской
версии к нему добавляется пояснение **Visa Centre** — оно задаётся в
`data/site.json`, поле `nameSuffix`.

### Ссылки hreflang

В `<head>` каждой страницы стоят ссылки на две другие языковые версии, на саму
себя и `x-default` на туркменскую. Их расставляет `sync-layout.js` — руками
их писать не надо.

Сейчас адреса относительные, потому что домен ещё не вписан. **Впишите домен
в `data/site.json` и запустите скрипт снова** — адреса станут полными, как
и предпочитают поисковики.

### Чего в этом сайте намеренно нет

- **Автоматического перехода** на язык по настройкам браузера или по стране.
  Язык выбирает человек, и выбор не должен сбрасываться.
- **Подмены текста скриптом.** Каждая версия — отдельные HTML-файлы, поэтому
  поисковики индексируют все три, а сайт работает при выключенном JavaScript.

## 4. СКОРОСТЬ И ПРОВЕРКИ ПЕРЕД ПУБЛИКАЦИЕЙ

Аудитория сайта сидит на медленном интернете, поэтому вес страниц — не
мелочь, а главное требование. Сейчас страница показывает первый текст
примерно за **1,5 секунды** при скорости 400 Кбит/с и задержке 400 мс.

### Как замерить самому

В одном окне Терминала запустите сервер:

```
node scripts/serve.js
```

Во втором — замер:

```
node scripts/measure-speed.js
```

Скрипт откроет Chrome без окна, включит медленную сеть и покажет таблицу:
за сколько появляется первый текст (FCP), самый крупный элемент (LCP),
сколько всего передано.

> Обычный `python3 -m http.server` тоже подойдёт, чтобы просто посмотреть
> сайт, но он не сжимает файлы, и замеры будут вдвое хуже реальности.
> Для замеров используйте `node scripts/serve.js`.

### Что уже сделано для скорости

- Шрифт обрезан до нужных символов: было 149 КБ, стало 49 КБ.
- Каждая языковая версия подгружает только свой набор символов:
  туркменская — латиницу с расширением, русская — латиницу и кириллицу,
  английская — только латиницу.
- Логотипы в svg пересчитаны с меньшей точностью координат: минус 15% веса
  без видимой разницы.
- Скрипты подключены с `defer` — они не задерживают показ страницы.
- Ни одного стороннего скрипта, счётчика и шрифта из интернета:
  всё своё, всё локально.

### Обязательная проверка перед публикацией

```
node scripts/sync-layout.js --check
```

Эта команда ничего не меняет и ругается, если:

- страница есть на одном языке, а на другом её нет;
- остался непереведённый кусок;
- у двух страниц одинаковый `title` или `description`;
- описание длиннее 160 символов;
- часы работы в разметке разошлись с теми, что видит человек;
- карта сайта или разметка устарели;
- в `data/site.json` остались незаполненные данные.

Пока она пишет «Публиковать рано» — публиковать рано.

### Если добавили текст с новыми символами

Шрифт содержит только те буквы, которые есть на сайте, плюс полные
туркменский, русский и английский алфавиты. Если вы вставите текст на
четвёртом языке, часть букв отрисуется системным шрифтом. Тогда:

```
python3 scripts/subset-fonts.py
```

Полные исходные шрифты лежат в `assets/fonts/full/` — не удаляйте их.

## 5. Как менять цвета

Все цвета собраны в одном месте — файл `css/tokens.css`, самый верх.
Меняете значение там — меняется на всём сайте сразу.

```css
--ink:          #31363D;  /* основной текст и заголовки */
--copper:       #AF5F39;  /* акцент, заливка кнопок */
--copper-dark:  #8F4A2B;  /* при наведении мышью; цвет ссылок в тексте */
--bg:           #FAFAF8;  /* фон страницы */
--surface:      #FFFFFF;  /* карточки */
--line:         #E3E1DC;  /* границы и разделители */
--muted:        #6E737B;  /* второстепенный текст */
--dark:         #2A2E35;  /* фон подвала */
```

> **Важно про читаемость.** Цвета подобраны так, чтобы текст было хорошо
> видно людям со слабым зрением и на солнце (это требование доступности).
> Если будете менять — не делайте текст светлее фона. Проверить пару
> «цвет текста / цвет фона» можно на сайте webaim.org/resources/contrastchecker
> — нужно значение не ниже **4.5**.
>
> Отдельно: ссылки внутри текста используют `--copper-dark`, а не `--copper`.
> Это не ошибка — обычный медный на светлом фоне даёт 4.4 и чуть-чуть не
> дотягивает до нормы, а тёмный даёт 6.3.

## 6. Как менять отступы и размеры шрифта

Там же, в `css/tokens.css`, ниже цветов.

**Отступы** — от самого маленького к самому большому:

```css
--space-1:  4px;   --space-4: 16px;   --space-7: 48px;
--space-2:  8px;   --space-5: 24px;   --space-8: 64px;
--space-3: 12px;   --space-6: 32px;   --space-9: 96px;
```

**Размеры шрифта.** У заголовков стоит `clamp(...)` — это «резиновый» размер:
на телефоне берётся первое число, на большом экране — последнее, между ними
размер меняется плавно. Например:

```css
--text-h1: clamp(2rem, 3.2vw + 1.25rem, 3rem);
              ↑ на телефоне            ↑ на большом мониторе
              32px                     48px
```

`1rem = 16px`. То есть `1.125rem` — это 18px.

**Ширина сайта:** `--container-max: 1200px`.

## 7. Как работает форма заявки

У сайта нет сервера, поэтому форма **никуда ничего не отправляет сама**.
Она собирает из полей аккуратное сообщение и даёт три кнопки:

| Кнопка | Что делает |
|---|---|
| Habarçy arkaly ibermek | открывает мессенджер с уже готовым текстом. Если у мессенджера нет такой возможности (у IMO её нет) — копирует текст и подсказывает, кому его переслать |
| E-poçta bilen ibermek | открывает почтовую программу с заполненными темой и текстом |
| Teksti göçürmek | просто копирует текст в буфер обмена |

Посетитель может заранее посмотреть, что отправится: под кнопками есть строка
«Iberiljek tekste seret».

### Почему в форме нет паспорта и сканов

Это сделано намеренно. **Не добавляйте в форму поля для номера паспорта,
даты рождения, финансовых данных и загрузки файлов.**

Сайт статический: у него нет сервера, нет базы данных и нет защищённого
канала. Личные документы, отправленные через такую форму, уходят открытым
текстом в мессенджер или почту, и защитить их нечем. Отвечать за утечку
придётся вам.

Поэтому под формой стоит прямая надпись: документы через сайт не отправляют,
их приносят в офис или передают при прямой связи.

## 8. Почему на страницах нет точных сроков и списков документов

Это сделано намеренно, и менять это опасно.

Требования консульств меняются, отличаются от страны к стране и зависят
от конкретного человека. Если написать на сайте точный список документов или
срок вроде «7 рабочих дней», клиент на него понадеется — и получит отказ.
Отвечать за это придётся вам.

Поэтому на страницах:

- списки документов **общие и очевидные** (паспорт, фото, анкета, бронь,
  страховка, подтверждение финансов);
- рядом с каждым списком стоит оговорка, что точный перечень уточняется
  на консультации;
- нигде нет консульских сборов, точных сроков и требований конкретной страны;
- нигде нет гарантии выдачи визы — решение принимает консул.

Если будете дописывать тексты, придерживайтесь того же правила:
**конкретика — только на консультации, на сайте — принцип работы.**

## 9. Про шрифт

Используется **Inter** — он поддерживает и туркменские буквы
(ä ü ý ş ň ž ç), и кириллицу для будущей русской версии. Всё проверено.

Шрифт скачан заранее и лежит в `assets/fonts/`. **Интернет для него не нужен,
ничего скачивать и подключать не надо.**

Файлов три, а не двенадцать, потому что Inter — «вариативный» шрифт: один
файл содержит сразу все толщины от тонкой до жирной.

| Файл | Размер | Для чего |
|---|---|---|
| `inter-latin.woff2` | 32 КБ | латиница, а также ä ü ý ç |
| `inter-cyrillic.woff2` | 13 КБ | кириллица — для русской версии |
| `inter-latin-ext.woff2` | 4 КБ | ş ň ž и другие туркменские буквы |

Файлы обрезаны до нужных символов — до обрезки они весили 149 КБ.
Полные исходники лежат в `assets/fonts/full/`, см. раздел 4.

Каждая версия сайта подгружает только свой набор: туркменская — первый
и третий файл (36 КБ), русская — первый и второй (45 КБ), английская —
только первый (32 КБ).

## 11. Если что-то сломалось

- **Пропали все стили, страница как из 90-х** — скорее всего, папка `css`
  переименована или лежит не рядом с `index.html`. Она должна быть в той же
  папке, что и `index.html`.
- **Не открывается меню на телефоне** — проверьте, что папка `js` на месте
  и файл `js/main.js` внутри.
- **Вместо ä ý ş видны квадратики** — проверьте, что папка `assets/fonts`
  на месте и в ней три файла `.woff2`.
- **Вместо букв квадратики** — в тексте появился символ, которого нет
  в обрезанном шрифте. Запустите `python3 scripts/subset-fonts.py`.
- **Сайт стал медленным** — проверьте `node scripts/measure-speed.js`
  и убедитесь, что на хостинге включено сжатие (`.htaccess` или
  `nginx.conf.example` лежат в корне).
- **Правил только русскую версию, туркменская осталась старой** — так и будет:
  версии независимы. Правьте все три и запускайте
  `node scripts/sync-layout.js --check`, он покажет расхождения.
- **Переключатель языков уводит на главную вместо нужной страницы** — значит,
  перевода этой страницы нет. Создайте файл с тем же именем в папке `ru/`
  или `en/`.
- **Поменял телефон, а на сайте старый** — забыли запустить
  `node scripts/sync-layout.js` после правки `data/site.json`.
- **На сайте видно слово ЗАПОЛНИТЬ** — эти данные ещё не вписаны
  в `data/site.json`. Полный список покажет `node scripts/sync-layout.js --check`.
- **Поменял меню, а на других страницах старое** — забыли запустить
  `node scripts/sync-layout.js`. Запустите, и всё разойдётся.
- **Правил меню прямо в странице, и правка пропала** — так и должно быть:
  всё между метками `<!-- header:start -->` и `<!-- header:end -->`
  перезаписывается. Правьте `partials/header.html`.
- **Перед правкой любого файла сделайте копию.** Если что-то пойдёт не так,
  просто вернёте старую версию.
